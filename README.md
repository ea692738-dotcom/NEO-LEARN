# NEO LEARN
منصة تعليمية ثابتة (Static Website) مبنية على منهج NEO LEARN ذي الـ16 أسبوعًا.

## التشغيل
افتح `index.html` في المتصفح.

## الرفع إلى GitHub
ارفع محتويات هذا المجلد إلى المستودع، ثم فعّل GitHub Pages من إعدادات المستودع.
ملفات المشروعين الأساسيين موجودة داخل مجلد `projects/`.

ملاحظة: روابط المصادر الخارجية تفتح من الإنترنت، بينما المنصة نفسها تعمل كصفحة Static ولا تحتاج إلى خادم.

## النسخة الجديدة
تمت إضافة صفحة تقدم مستقلة، دائرة تقدم بنفس لون هوية الشعار، زر ابدأ المسار، زر ابدأ التعلم، ودعم Light/Dark Mode.
